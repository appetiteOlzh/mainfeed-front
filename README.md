# MainFeed

Лендинг на Next.js App Router, React и TypeScript. Для разработки используйте Node.js 22.14+ и pnpm.

```sh
pnpm install
pnpm dev
```

| Команда | Назначение |
| --- | --- |
| `pnpm build` | Production-сборка с Turbopack |
| `pnpm build:webpack` | Production-сборка с webpack |
| `pnpm start` | Запуск собранного приложения |
| `pnpm lint` | Проверка ESLint |
| `pnpm typecheck` | Проверка типов приложения |
| `pnpm storybook` | Каталог компонентов на порту 6006 |
| `pnpm build-storybook` | Статическая сборка каталога |
| `pnpm typecheck:storybook` | Проверка типов историй и конфигурации Storybook |

## Структура

- `app/` собирает главную страницу и метаданные. В `app/landing/` находятся контроллеры прокрутки, которые синхронизируют несколько секций.
- `src/widgets/` содержит четыре секции лендинга. Компоненты импортируются через публичный интерфейс виджета.
- `src/shared/ui/` содержит общее демо телефона и кнопки магазинов. Истории Storybook лежат рядом с реализацией.
- `src/shared/styles/theme.css` задаёт токены Tailwind. Приложение и Storybook подключают один файл `app/globals.css`.
- `public/assets/` содержит изображения, видео и шрифты. Автономную HTML-версию можно открыть по адресу `/MainFeed-preview.html`.

Компоненты секций рендерятся на сервере. Клиентский компонент `LandingMotion` подключает контроллеры после монтирования и освобождает их ресурсы при уходе со страницы. Исходная статическая версия находится в `MainFeed-site/`. Сборка приложения использует файлы из `app/`, `src/` и `public/`.
